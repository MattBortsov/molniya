# Правила и архитектурные стандарты проекта «Молния Тех» (molniya-tech.ru)

## 1. Строгая политика безопасности CSP (Content Security Policy)
- В `nginx/security_headers.conf` задана строгая директива:
  `script-src 'self'` (без `'unsafe-inline'`).
- **ЗАПРЕЩЕНО:**
  - Вставлять инлайн-скрипты `<script>...</script>` в HTML страниц. Браузер блокирует их выполнение на проде из-за CSP.
  - Использовать инлайн-обработчики событий в HTML-атрибутах (`onclick="..."`, `onchange="..."` и т.д.).
- **ОБЯЗАТЕЛЬНО:**
  - Весь JavaScript-код должен находиться строго во внешнем файле `/script.js`.
  - Интерактивность привязывается через селекторы классов (`.mt-btn-...`, `data-*`) внутри `script.js` (в функциях инициализации `DOMContentLoaded` / `initApp()`).
  - При любых изменениях в `script.js` или `styles.css` необходимо инкрементировать версию кэш-бастинга (`?v=YYYYMMDD-...`).

## 2. Чистые человекопонятные URL (Clean URLs) без `.html`
- **ЗАПРЕЩЕНО:**
  - Использовать расширение `.html` в публичных ссылках на страницы сайта (нельзя писать `/auto.html`, `/requisites.html` и т.д.).
- **ОБЯЗАТЕЛЬНО:**
  - Все внутренние ссылки на сайте (навигация, меню, подвал, кнопки) должны указывать на чистый URL: `/auto`, `/requisites`, `/blog`, `/beauty`.
  - `/health` остаётся доступной страницей с canonical и в sitemap, но на неё не ставятся ссылки из интерфейса сайта.
  - Мета-теги `<link rel="canonical" href="https://molniya-tech.ru/<slug>">` и Open Graph `<meta property="og:url" content="https://molniya-tech.ru/<slug>">` обязаны быть чистыми (без `.html`).
  - В `sitemap.xml` страницы добавляются исключительно в виде чистых URL: `https://molniya-tech.ru/<slug>`.
  - В конфигурации `nginx/nginx.conf` для обратной совместимости настраивается относительный 301-редирект:
    `location = /<slug>.html { return 301 /<slug>; }`
    (в блоке `server` обязательно включена директива `absolute_redirect off;`, чтобы редиректы не сбрасывали протокол на HTTP).

## 3. DRY-генератор страниц и синхронизация
- Страницы секторов, служебные страницы (404, реквизиты) и карта сайта генерируются скриптом `scripts/build_sector_pages.py`.
- Изменения общей навигации (`nav`), подвала (`footer`), ссылок и глобальной структуры вносятся в `scripts/build_sector_pages.py`, после чего выполняется пересборка:
  ```bash
  python3 scripts/build_sector_pages.py
  ```
- Скрипт синхронизирует меню и подвал на `index.html`, `blog/index.html` и формирует готовые HTML-страницы.

## 4. Универсальный буфер обмена (Копирование текста)
- **ЗАПРЕЩЕНО:** Полагаться только на `navigator.clipboard.writeText(...)` без фоллбека. В браузерах Telegram/VK WebApp, Safari iOS или на страницах без фокуса данный API блокируется или выбрасывает ошибку.
- **ОБЯЗАТЕЛЬНО:**
  - Любое копирование в буфер должно реализовываться с фоллбеком через скрытый `<textarea>` и `document.execCommand('copy')`.
  - Для интерактивных кнопок («Скопировать») необходимо сохранять исходный текст/HTML, переключать класс `.copied` и возвращать исходное состояние по таймеру с очисткой предыдущего таймаута при быстрых повторных кликах.
